## 結論

オキュペイショナルハイジニストは、職場にある有害因子を**予測し、認識し、評価し、管理する**ことを通じて、労働者の健康障害を予防する労働衛生の専門家です。

日本では公益社団法人日本作業環境測定協会（日測協）が「IOHA認証日測協認定オキュペイショナルハイジニスト」を認定しています。作業環境測定だけに限定されず、化学物質、物理的因子、生物学的因子、人間工学的因子などを横断して、リスクアセスメントから対策まで扱う点が大きな特徴です。

資格そのものは日測協の認定資格であり、作業環境測定士や労働衛生コンサルタントとは制度が異なります。一方、2026年10月からは個人ばく露測定に関して法令上の重要な位置づけも加わります。

## オキュペイショナルハイジーンとは

オキュペイショナルハイジーン（Occupational Hygiene）は、職場の有害因子による健康リスクを扱う専門分野です。

基本的な考え方は次の流れで整理できます。

1. **予測する（Anticipate）**：工程や物質から、起こり得るばく露を考える
2. **認識する（Recognize）**：有害因子とばく露経路を特定する
3. **評価する（Evaluate）**：測定や情報からリスクの程度を評価する
4. **管理する（Control）**：代替、密閉化、局所排気、作業方法、保護具などでリスクを下げる

つまり「濃度を測定する人」だけではありません。測定値を得る前の調査から、結果を使った改善、残留リスクの管理までを一つの流れとして扱います。

## オキュペイショナルハイジニストの仕事

日測協の制度趣旨や倫理規程では、オキュペイショナルハイジニストは、事業者が行うリスクアセスメントやリスクマネジメントを専門的・技術的に支援する高度な実務家・専門家として位置づけられています。

実務では、例えば次のような領域を扱います。

- 化学物質や粉じんの危険有害性の把握
- 作業・工程・発散源・換気の調査
- 作業環境測定、個人ばく露測定などを用いたばく露評価
- リスクアセスメント
- 代替、密閉化、局所排気装置などの工学的対策
- 作業方法・管理手順の改善
- 呼吸用保護具などの選定に必要な評価
- 騒音、暑熱などの物理的因子への対応
- 人間工学的なリスクの評価
- 対策後の再評価
- リスクコミュニケーション

測定結果だけでなく、**「なぜ高いのか」「何を優先して変えるか」「改善後にどう確認するか」まで扱う**のがハイジニストの専門性です。

## 日本の認定制度とIOHA

日測協は2008年からオキュペイショナルハイジニスト養成プログラムを開始し、2010年度から認定者が生まれています。

2014年には、国際オキュペイショナルハイジーン協会（IOHA）の国別認証制度であるNAR（National Accreditation and Recognition）による認証を受けました。日測協によると、非英語圏では初の認証でした。

英語表記としては、日測協が **Certified Occupational Hygienist**、または **Certified Occupational Hygienist（IOHA-recognized）** の例を示しています。

## 認定を受けるための5つの主な要件

2026年4月1日施行の規程では、認定申請時に主として次の要件をすべて満たす必要があります。

| 要件 | 内容 |
| --- | --- |
| 資格 | 第1種作業環境測定士、労働衛生コンサルタント、衛生工学衛生管理者、第1種衛生管理者、産業医、または日測協が同等以上と認める資格 |
| 実務経験 | 作業環境管理その他の労働衛生管理について5年以上 |
| 学歴等 | 理工学・医学系等の学士、または日測協が同等以上と認める条件 |
| 養成講座 | 12コースを修了し、93単位を取得 |
| 評価試験 | 評価試験に合格し、合格後2年以内に認定申請 |

ここで重要なのは、**養成講座を受け始める時点で、これらをすべて満たしている必要はない**ことです。

日測協のFAQでは、養成講座そのものは資格や業務経験の有無にかかわらず受講できると案内されています。認定を受ける時点で必要な条件を満たしているかを確認します。

## 93単位とは

オキュペイショナルハイジニスト養成講座は**コース1～12、合計93単位**で構成されています。

93単位という数字だけを見ると「長い資格講習」に見えますが、目的は単一の測定技術を覚えることではありません。ばく露評価、リスク評価、健康影響、対策、リスクコミュニケーションなど、オキュペイショナルハイジーンを横断して学ぶ構成です。

日測協は現在、養成講座を主としてオンデマンド形式で実施しています。年度ごとに配信期間や申込期間が決まるため、受講する年の案内を確認します。

## 評価試験

養成講座で93単位を取得すると、認定オキュペイショナルハイジニスト評価試験を受験できます。

2026年度の試験案内では、試験は次の構成です。

| 試験 | 2026年度の形式 |
| --- | --- |
| 多肢選択式① | 4肢択一 40問・120分 |
| 多肢選択式② | 4肢択一 30問・90分 |
| 記述式 | 4問から3問を選択・150分 |

2026年度の受験料は16,500円（税込）で、第25回が4月14日、第26回が10月14日に設定されています。

評価試験の受験自体に必要なのは93単位の履修です。試験に合格しても、認定申請時に資格・実務経験・学歴等の要件を満たしていなければ、直ちに認定されるわけではありません。

合格証は2年間有効とされているため、この期間内に認定要件を満たして申請します。

## 取得までの流れ

大まかな流れは次のとおりです。

1. 現在の資格・学歴・実務経験を確認する
2. 日測協の養成講座コース1～12を受講する
3. 93単位を取得する
4. 評価試験を受験する
5. 評価試験に合格する
6. 認定要件をすべて満たした状態で認定申請する
7. 認定審査を経て認定を受ける

2026年度から、新規認定申請と更新認定申請はJAWE-NAVI上の電子申請になっています。

## 5年ごとの更新が必要

認定資格は**5年間有効**で、更新しない場合は資格を失います。

更新では、単に更新料を支払うだけではなく、継続的な実務や研修などを通じて専門性を維持していることが求められます。

2026年4月の制度改正では、更新の評点カテゴリーが見直され、「ハイジニスト実践講座」が新設されました。また、5年間のうち1回は「ハイジニスト倫理教育」を受講することが必須とされています。

取得がゴールではなく、**継続的な専門能力の維持まで含めた認定制度**と考えると分かりやすいです。

## 作業環境測定士との違い

|  | オキュペイショナルハイジニスト | 作業環境測定士 |
| --- | --- | --- |
| 制度 | 日測協の認定制度・IOHA認証プログラム | 作業環境測定法に基づく資格 |
| 主な視点 | 有害因子の予測・認識・評価・管理 | 作業環境測定のデザイン、サンプリング、分析 |
| 対象範囲 | 化学・物理・生物・人間工学など幅広い | 登録区分や法令に基づく作業環境測定 |
| 特徴 | リスク評価から対策まで横断的に扱う | 測定の法定実施者としての役割を担う |

両者は競合する資格というより、専門性が重なる部分と異なる部分があります。

作業環境測定士として現場を測定できても、「結果から対策全体をどう設計するか」という視点は別途深める必要があります。逆に、ハイジニストとして幅広いリスク管理能力があっても、法令上作業環境測定士の登録が必要な業務を資格なしで行えるわけではありません。

## 労働衛生コンサルタントとの違い

労働衛生コンサルタントは、労働安全衛生法に基づき、他人の求めに応じ報酬を得て、事業場の衛生を診断し、その結果に基づく指導を行う専門家です。

一方、オキュペイショナルハイジニストは、職場の健康リスクを技術的に予測・評価・管理する専門性を中心にした認定制度です。

両方とも高度な労働衛生専門職ですが、制度上の根拠と資格の性格が異なります。

また、日測協の2024年8月時点の公表データでは、認定オキュペイショナルハイジニストのうち作業環境測定士資格を持つ人が75％、労働衛生コンサルタント資格を持つ人が44％でした。複数資格を組み合わせて専門性を広げている人も少なくありません。

## 化学物質管理専門家・作業環境管理専門家との関係

厚生労働省の通達では、日測協認定オキュペイショナルハイジニストやIOHAの国別認証を受けた海外資格者は、一定の「化学物質管理専門家」や「作業環境管理専門家」の要件に該当する者として示されています。

例えば、改善困難な第三管理区分となった作業場所で意見を聴く「作業環境管理専門家」の要件にも、オキュペイショナルハイジニストが含まれています。

ただし、実際にどの法令上の役割を担うかは、その制度の要件を個別に確認します。

## 2026年10月から個人ばく露測定との関係が変わる

<aside class="chemical-disclaimer" aria-label="2026年10月施行の制度改正に関する注意">
<strong>2026年9月2日時点では、2026年10月1日に施行予定です</strong>
<p>公布済みの法令・告示と厚生労働省通達に基づいて整理しています。施行後に制度運用を再確認し、必要に応じて記事を更新します。</p>
</aside>

2026年10月1日から、個人ばく露測定が作業環境測定の一部として法令上明確に位置づけられます。

同時に、厚生労働省告示第279号では、日測協認定オキュペイショナルハイジニストやIOHAの国別認証を受けた海外のオキュペイショナルハイジニスト等が、**個人ばく露測定のデザイン及びサンプリングについて十分な知識・技能を有する者**として指定されました。

この制度により、該当するオキュペイショナルハイジニストは、試験合格等を経ていなくても、**個人ばく露測定のデザイン・サンプリングに限って行うことができる第二種作業環境測定士となる資格**を有する仕組みが設けられます。

ただし、ここは誤解しやすい点です。

**オキュペイショナルハイジニストの認定を持っているだけで、自動的に作業環境測定士として法定の測定業務を行えるという意味ではありません。** 実際に作業環境測定士として業務を行うには、作業環境測定士名簿への登録など、制度上必要な手続を確認する必要があります。

すでに作業環境測定士として登録されているオキュペイショナルハイジニスト等については、2026年10月1日前から登録証の書換え申請を行うことができる経過措置も設けられています。

## 作業環境測定士が取得するメリット

作業環境測定士にとって、オキュペイショナルハイジニストを学ぶ価値は、「測定できる物質や分析機器が増える」という単純なものではありません。

特に次の力を体系的に補強できます。

- 測定前のハザード認識
- 個人ばく露評価
- リスクアセスメント
- 対策の優先順位
- 工学的対策の考え方
- 測定結果を改善へ結び付ける視点
- 残留リスク管理
- リスクコミュニケーション

作業環境測定の結果を報告書で終わらせず、改善提案や自律的な化学物質管理までつなげたい人には相性のよい専門領域です。

## 取得前に確認すること

認定を目指す場合は、まず次を確認します。

- [ ] 認定対象となる資格を持っているか、または取得予定か
- [ ] 労働衛生管理に関する実務経験が5年以上あるか
- [ ] 学士等の要件を満たしているか
- [ ] 93単位をどの期間で履修するか
- [ ] 評価試験の受験時期をいつにするか
- [ ] 合格後2年以内に認定申請できる見込みがあるか
- [ ] 認定後の5年更新も含めて継続学習できるか

受講開始時点では資格・実務経験が不足していても、養成講座自体は受講できます。将来の認定時点から逆算して計画すると整理しやすくなります。

## まとめ

- オキュペイショナルハイジニストは、職場の有害因子を予測・認識・評価・管理する労働衛生の専門家
- 日測協の認定制度はIOHAの国別認証を受けている
- 認定には対象資格、5年以上の実務経験、学士等、93単位、評価試験合格などが必要
- 養成講座は認定要件を満たす前から受講できる
- 認定は5年更新制で、継続的な研修・活動が求められる
- 作業環境測定士とは役割が異なり、ハイジニスト資格だけで法定測定を自由に行えるわけではない
- 2026年10月から、個人ばく露測定に限定した第二種作業環境測定士の資格・登録との関係が制度化される

**最終更新日・一次情報確認日：2026年9月2日**
